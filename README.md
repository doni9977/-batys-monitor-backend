# Batys Monitor Backend 🚨

Система для выявления экономических рисков в рамках медицинского страхования по ЗКО.

## Описание проекта

Batys Monitor автоматически анализирует реестры медицинских услуг (Excel-файлы на 100,000+ строк) и выявляет паттерны фрода (ущерба) на основе загружаемого классификатора медицинских услуг.

### Реализованные алгоритмы рисков:
- **A1** — Нарушение возрастных ограничений
- **A2** — Нарушение половых ограничений
- **A3** — Аномальная нагрузка врача (> 80 услуг/час)
- **A4** — Дублирование услуг / Превышение дневного лимита
- **A7** — Нарушение годового лимита
- **A8** — Завышение стоимости (upcoding)
- **A10** — Нарушение временного интервала (пересечение услуг по времени)

## Стек технологий
- **Golang 1.25** (Fiber)
- **PostgreSQL 15** + PostGIS (Docker)
- **GORM**
- **Excelize** (Парсинг Excel)

## Быстрый старт

### 1. Подготовка
Создайте файл `.env` из `.env.example`:
```bash
cp .env.example .env
```
*(При необходимости измените `DB_PASSWORD` и другие параметры).*

### 2. Запуск БД
Запустите PostgreSQL через Docker:
```bash
docker-compose up -d
```
*Убедитесь, что порт 5440 свободен.*

### 3. Запуск сервера
Запустите бэкенд на Go:
```bash
go mod tidy
go run cmd/main.go
```
Сервер запустится на `http://localhost:3000`.

## API Endpoints

### Загрузка данных
- `POST /api/upload-classifier` — Загрузка файла-классификатора.
- `POST /api/upload` — Загрузка реестра медицинских услуг (очищает предыдущие данные).

### Получение рисков (Пагинация)
- `GET /api/risks/a1?page=1&limit=100` — Возрастные нарушения.
- `GET /api/risks/a2?page=1&limit=100` — Половые нарушения.
- `GET /api/risks/a3?page=1&limit=100` — Аномальная нагрузка врача.
- `GET /api/risks/a4?page=1&limit=100` — Дублирование/Превышение лимита в день.
- `GET /api/risks/a7?page=1&limit=100` — Превышение лимита в год.
- `GET /api/risks/a8?page=1&limit=100` — Завышение стоимости.
- `GET /api/risks/a10?page=1&limit=100` — Нарушение интервала.

> **Фильтры:** `?doctor=Имя`, `?clinic=Имя`, `?date_from=2024-01-01`, `?date_to=2024-12-31`.

### Дашборд и Экспорт
- `GET /api/summary` — Сводная статистика (количество и ущерб по всем A1-A10).
- `GET /api/clinics/risks` — Статистика по клиникам для отображения на карте.
- `GET /api/export/xlsx?indicator=A10` — Выгрузка результатов в Excel файл.
